# ⚡ PowerGuard – Electricity Wastage Detection System

## 1. Project Overview
PowerGuard is a web-based dashboard designed to monitor electricity usage and help identify unnecessary energy consumption.

## 2. Problem Statement
Lights, fans, and air conditioners are sometimes left running in empty rooms. This wastes electricity and increases electricity bills.

## 3. Project Objectives
- Monitor appliance power consumption.
- Display estimated electricity usage and wastage.
- Track estimated money wasted.
- Provide room monitoring and alert information.
- Encourage energy-saving habits.

## 4. Technology Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Python Flask
- Charts: Chart.js
- Code Editor: Visual Studio Code
- Version Control: GitHub

## 5. System Architecture
1. Users access the dashboard through a web browser.
2. Flask handles application routes and requests.
3. HTML creates the dashboard structure.
4. CSS styles the interface.
5. JavaScript updates interactive dashboard values.
6. Chart.js presents energy information visually.

## 6. Components Developed
- app.py – Flask application and routes.
- dashboard.html – Main energy dashboard.
- login.html – Login interface.
- rooms.html – Room monitoring interface.
- style.css – Dashboard styling.
- script.js – Interactive dashboard functionality.
- README.md – Project documentation.

## 7. Implementation Status
The application runs locally using Flask. The dashboard interface and project files have been created and uploaded to GitHub.

## 8. Testing
Initial testing confirmed that the application opens locally and the dashboard loads in the browser. Further testing of calculations, alerts, and different input conditions is required.

## 9. Review Improvements

## 10. Future Enhancements

## 11. Conclusion
PowerGuard aims to help users understand electricity consumption, identify potential wastage, and make better energy-saving decisions.
